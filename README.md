# CHEESY-CRUST-CO

Restaurant ordering, reservation, admin, and payment system.

## Hostinger Node.js Backend

Use `backend-node` for Hostinger Node.js hosting.

```bash
cd backend-node
npm install
npm start
```

See `docs/HOSTINGER_NODEJS_DEPLOYMENT.md` for deployment steps and required environment variables.

The `backend` folder is the previous Python/FastAPI backend and is kept as legacy reference.
